## 3. 调研方法

### 3.1 浏览器自动化调研

使用 agent-browser 工具进行深度调研：

1. **登录系统**
   - 访问登录页面
   - 输入账号密码
   - 截图保存登录状态

2. **逐页面调研**
   - 进入每个功能页面
   - 等待数据加载
   - 截图并提取数据
   - 记录字段信息

3. **数据提取**
   - 提取表格数据（转CSV/JSON）
   - 提取表单字段
   - 提取下拉选项
   - 提取按钮操作

### 3.2 调研输出

每个页面生成：
- 截图文件（PNG）
- 数据文件（JSON）
- 字段说明文件（MD）

## 4. 核心调研点

### 4.1 原材料供应商关联（重点）

原系统核心功能，必须完整调研：

```
原材料管理页面 → 切换到供应商关联标签页
```

**必须捕获的数据：**
- 原材料基本信息（编号、名称、规格、单位）
- 供应商关联列表
  - 供应商名称
  - 供应商产品代码
  - 供应商产品名称
  - 采购价
  - 关联状态
- 操作按钮（添加、编辑、删除）

### 4.2 报价单完整流程

**必须捕获的数据：**
- 报价单主表字段
- 产品明细（产品名、数量、单价、金额）
- 报价转订单功能
- 状态变更

### 4.3 销售/采购订单

**必须捕获的数据：**
- 订单主表字段
- 订单明细结构
- 状态流转
- 关联应收/应付
