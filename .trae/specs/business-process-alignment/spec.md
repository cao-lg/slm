## 3. 销售管理业务流程

### 3.1 模块概述

销售管理模块负责处理客户询价、销售报价、销售订单、销售发货、应收款回收等业务。

**核心业务流程**：
```
询价接待 → 生成报价单 → （报价接受）→ 转为销售订单 → 生产/备货 → 发货出库 → 开具应收 → 收款核销
```

### 3.2 报价单管理

#### 3.2.1 功能描述
- **功能入口**：销售管理 → 报价单
- **ASP文件**：ProksBJ.asp
- **核心业务**：接待客户询价，生成报价单据

#### 3.2.2 业务流程
```
1. 选择客户（从客户列表选择或新增客户）
   ↓
2. 添加产品明细
   ├── 选择产品（从产品目录选择）
   ├── 输入数量
   ├── 输入单价（或从产品默认单价带入）
   └── 系统自动计算金额（数量 × 单价）
   ↓
3. 填写报价信息
   ├── 报价日期（默认当天）
   ├── 有效期至（可选择）
   └── 备注说明（可选）
   ↓
4. 保存报价单
   └── 系统自动生成报价单号（格式：BJ + 年月日 + 序号）
   ↓
5. 报价单状态流转
   ├── pending（待确认）→ 报价单刚创建
   ├── accepted（已接受）→ 客户确认接受报价
   └── rejected（已拒绝）→ 客户拒绝报价
   ↓
6. 报价转订单（可选）
   └── 已接受的报价单可以转为销售订单
```

#### 3.2.3 核心字段

**报价单主表**：
| 字段 | 类型 | 说明 | 必填 |
|------|------|------|------|
| 报价单号 | VARCHAR | 系统自动生成，格式：BJ+年月+序号 | 是 |
| 客户名称 | VARCHAR | 从客户列表选择 | 是 |
| 报价日期 | DATETIME | 默认当天 | 是 |
| 有效期至 | DATETIME | 报价有效期 | 否 |
| 报价总额 | DECIMAL | 系统自动计算 | 是 |
| 状态 | VARCHAR | pending/accepted/rejected | 是 |
| 制单人 | VARCHAR | 当前登录用户 | 是 |

**报价单明细**：
| 字段 | 类型 | 说明 | 必填 |
|------|------|------|------|
| 产品名称 | VARCHAR | 从产品目录选择 | 是 |
| 规格 | VARCHAR | 从产品档案带入 | 否 |
| 单位 | VARCHAR | 从产品档案带入 | 是 |
| 数量 | DECIMAL | 用户输入 | 是 |
| 单价 | DECIMAL | 用户输入或默认单价 | 是 |
| 金额 | DECIMAL | 系统计算（数量×单价） | 是 |

### 3.3 销售订单管理

#### 3.3.1 功能描述
- **功能入口**：销售管理 → 销售订单
- **ASP文件**：HTPI.asp
- **核心业务**：管理客户销售订单，记录订单详情

#### 3.3.2 业务流程
```
1. 创建订单
   ├── 方式一：直接从报价单转为订单（已接受的报价单）
   │   └── 自动带入客户、产品明细、单价
   └── 方式二：手动创建订单
       └── 手动选择客户和产品
   ↓
2. 填写订单信息
   ├── 订单日期（默认当天）
   ├── 客户名称（必选）
   ├── 交货日期（必填）
   └── 备注说明（可选）
   ↓
3. 添加订单明细
   ├── 选择产品（从产品目录选择）
   ├── 输入数量
   ├── 输入单价
   └── 系统自动计算金额
   ↓
4. 保存订单
   └── 系统自动生成订单号（格式：XS + 年月日 + 序号）
   ↓
5. 订单状态流转
   ├── pending（已下单）→ 订单刚创建
   ├── producing（生产中）→ 订单正在生产
   ├── shipped（已发货）→ 已完成发货
   └── completed（已完成）→ 订单全部完成
   ↓
6. 发货处理（从仓库模块）
   └── 根据订单生成发货单
   ↓
7. 应收款生成
   └── 订单完成后自动生成应收款记录
```

#### 3.3.3 核心字段

**销售订单主表**：
| 字段 | 类型 | 说明 | 必填 |
|------|------|------|------|
| 订单号 | VARCHAR | 系统自动生成，格式：XS+年月+序号 | 是 |
| 客户名称 | VARCHAR | 从客户列表选择 | 是 |
| 订单日期 | DATETIME | 默认当天 | 是 |
| 交货日期 | DATETIME | 客户要求交货日期 | 是 |
| 订单总额 | DECIMAL | 系统自动计算 | 是 |
| 状态 | VARCHAR | pending/producing/shipped/completed | 是 |
| 制单人 | VARCHAR | 当前登录用户 | 是 |

**销售订单明细**：
| 字段 | 类型 | 说明 | 必填 |
|------|------|------|------|
| 产品名称 | VARCHAR | 从产品目录选择 | 是 |
| 规格 | VARCHAR | 从产品档案带入 | 否 |
| 单位 | VARCHAR | 从产品档案带入 | 是 |
| 数量 | DECIMAL | 用户输入 | 是 |
| 单价 | DECIMAL | 用户输入或默认单价 | 是 |
| 金额 | DECIMAL | 系统计算 | 是 |

**核心业务流程**：
```
入库：采购收货 → 填入库单 → 更新库存
出库：领料/发货 → 填出库单 → 更新库存
调拨：仓库调拨 → 填调拨单 → 更新库存
退货：退货处理 → 填退货单 → 更新库存
```

### 6.2 仓库分类

#### 6.2.1 五种仓库类型

| 仓库代码 | 仓库名称 | 类型 | 用途 |
|---------|---------|------|------|
| KCA | 车间仓 | 车间仓 | 生产车间原料和半成品暂存 |
| KCB | 成品仓 | 成品仓 | 生产的成品存储 |
| KCC | 材料仓 | 材料仓 | 采购的原材料存储 |
| KCD | 外仓 | 外仓 | 外协加工物资存储 |
| KCE | 待处理仓 | 待处理仓 | 退货、待检等物资 |

### 6.3 发货单管理

#### 6.3.1 功能描述
- **功能入口**：仓库管理 → 发货单
- **ASP文件**：KCFH.asp
- **核心业务**：根据销售订单生成发货单，记录发货详情

#### 6.3.2 业务流程
```
1. 创建发货单
   ├── 关联销售订单（必选）
   │   └── 自动带入客户信息、产品明细
   ├── 输入发货日期（默认当天）
   ├── 确认发货数量
   └── 备注说明（可选）
   ↓
2. 发货明细
   ├── 产品信息（从订单带入）
   ├── 订单数量（从订单带入）
   ├── 已发货数量（已完成的发货单汇总）
   ├── 本次发货数量（本次实际发货）
   └── 剩余数量（订单数量 - 已发货 - 本次发货）
   ↓
3. 保存发货单
   ↓
4. 更新库存
   └── 从成品仓（KCB）扣除相应数量
```

**核心业务流程**：
```
销售收款：销售订单 → 生成应收款 → 收款核销
采购付款：采购订单 → 生成应付款 → 付款核销
费用报销：员工申请 → 审批 → 报销付款
```

### 7.2 应收款管理

#### 7.2.1 功能描述
- **功能入口**：财务管理 → 应收管理
- **ASP文件**：OAS.asp
- **核心业务**：管理客户应收款项

#### 7.2.2 业务流程
```
1. 应收款生成
   └── 销售订单完成后自动生成应收款记录
   ↓
2. 应收款信息
   ├── 应收单号（系统自动生成）
   ├── 客户名称
   ├── 关联销售订单
   ├── 应收金额（订单总额）
   ├── 已收金额
   ├── 到期日期
   └── 状态（未付款/部分付款/已付清）
   ↓
3. 收款核销
   ├── 录入收款信息
   │   ├── 收款金额
   │   ├── 收款日期
   │   └── 收款方式（现金/转账/票据）
   └── 更新已收金额和状态
   ↓
4. 应收款状态流转
   ├── unpaid（未付款）→ 未收款
   ├── partial（部分付款）→ 部分收款
   └── paid（已付清）→ 全部收款
```

   ├── 已付金额

   └── 状态（未付款/部分付款/已付清）

   ├── 录入付款信息
   │   ├── 付款金额
   │   ├── 付款日期
   │   └── 付款方式（现金/转账/票据）
   └── 更新已付金额和状态
   ↓
4. 应付款状态流转
   ├── unpaid（未付款）
   ├── partial（部分付款）

   ├── 录入付款信息
