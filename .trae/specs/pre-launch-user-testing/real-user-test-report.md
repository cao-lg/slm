## 六、修复建议

### 6.1 网络问题临时解决方案

**方案1: 使用国内Maven镜像**
修改 `erp-backend/pom.xml` 添加阿里云镜像:
```xml
<repositories>
  <repository>
    <id>aliyun</id>
    <url>https://maven.aliyun.com/repository/public</url>
  </repository>
</repositories>
```

**方案2: 使用预构建的Docker镜像**
- 使用 `docker-compose.yml` 中的配置
- 可能需要预先在网络正常的环境构建

**方案3: 本地已有依赖缓存**
- 检查 `~/.m2/repository` 是否有缓存
- 使用 `-o` 离线模式启动
